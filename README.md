# Jane Wilson Cannabis Dispensary

New North York storefront site based on the proven JFC01 five-tier information architecture, reworked around Jane Wilson's green and purple storefront artwork.

## Inventory boundary

The five weed routes and weight-price UI are complete. The public menu intentionally remains empty until `JWCD01` has its own governed FMD mapping. JFC01 stock is a design/structure reference only and is never represented as Jane Wilson live availability.
